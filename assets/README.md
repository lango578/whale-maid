## 🖼️ 三视图素材

角色的三张参考图（前 / 中 / 后）约定命名如下：

| 视角 | 文件 |
|---|---|
| 前 | `front.png` |
| 中 | `side.png` |
| 后 | `back.png` |

> 替换说明：将原作者提供的图片放入本目录并按下表命名后，应用默认形象即使用该素材（见 `docs/avatar.md` 的接入方式）。
