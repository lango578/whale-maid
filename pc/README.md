# 鲸鱼娘·汐汐 —— 电脑端（Windows 11）

DeepSeek 女仆鲸鱼娘的桌面伴侣应用。纯本地运行，只在你发送消息时调用 DeepSeek API。

## 两种打开方式

### 方式 A：零安装网页版（推荐先用这个）
直接双击 `whale-maid-pc.html`，用 **Edge 或 Chrome** 打开即可。
- 优点：不用装任何东西，立刻能玩。
- 局限：① 若 DeepSeek 服务器对浏览器直连有跨域限制，会提示「CORS」，这时请用方式 B；② 没有桌面悬浮窗。

### 方式 B：Electron 桌面版（真正的 exe 应用，推荐）
需要先安装 [Node.js](https://nodejs.org)（LTS 即可），然后：

```powershell
cd d:\Projects\whale-maid\pc\electron
npm install
npm start          # 直接运行
npm run dist       # 打包成安装包，生成到 dist/ 目录（鲸鱼娘汐汐 Setup.exe）
```

桌面版额外能力：
- 🐳 **桌面透明悬浮窗**：点顶栏「✨ 悬浮」，汐汐会变成一个可拖动的小鲸鱼娘飘在你桌面上，全屏玩游戏也看得到。
  - 按住小鲸鱼娘可拖动位置
  - `Ctrl + Shift + O` 切换「鼠标穿透」（让鼠标点透到游戏里，汐汐只负责陪伴和加油）
  - 主窗口里聊天时，她的回应会同步显示在悬浮窗的气泡里
- 因为以 `file://` 本地方式运行，不受浏览器跨域限制，直连 DeepSeek 更稳。

## 使用方法

1. **获取 API Key**：打开 https://platform.deepseek.com → 注册 → 左侧「API Keys」→ 创建（充值几块钱就够玩很久）。
2. 打开应用 → 点右上角「⚙️ 设置」→ 粘贴 API Key → 保存。
3. 开始聊天！Enter 发送，🎤 语音输入，🔊 语音播报（可关闭）。
4. **切换人格**：顶栏「🐳 汐汐 / 🦈 澜澜」一键切换。鲸鱼娘（温柔治愈）⇄ 鲨鱼娘（元气傲娇）的提示词、手绘形象（发色/尾巴/虎牙/女仆装）、互动台词全部同步换装，切换后她会用人设打招呼。
5. **后台模式（手机/电脑互通）**：设置里「连接方式」选「后台模式」→ 填后端地址与同步口令（见 `..\server\README.md` 启动后端）→ 设置面板「⬇️ 从云端拉取 / ⬆️ 同步到云端」即可把聊天记录、设置、当前人格同步到手机；后台模式下 API Key 无需填在前端（存后端 config.json）。
6. **陪玩**：点「🎮 陪玩」→ 输入游戏名 → 开始陪玩 → 每局后点「赢了/输了」，汐汐会陪你欢呼或帮你复盘，还能开悬浮窗飘在游戏上。
7. **陪看**：点「🎬 陪看」→ 选本地视频 / 粘贴 B站或YouTube链接 / 直链 → 和汐汐一起看，边看边聊剧情。
8. **戳戳她**：点虚拟形象的头 / 脸颊 / 尾巴 / 肩膀，她会害羞、脸红、甩尾巴，还有小剧场反应～

## 常见问题

- **点发送没反应/提示填 API Key**：右上角设置里填 Key 并保存。
- **提示 CORS/无法连接**：用方式 B（Electron）打开。
- **语音没声音**：Windows 设置里选一个支持中文的语音（设置→时间和语言→语音→添加语音），或者换个浏览器。
- **API Key 安全**：只保存在本机浏览器/应用的本地存储中，不会上传到别处。
